# 和 AI 一起学习：界面优化说明

## 方向

让访客先读到最近的真实学习记录，再沿着问题查看实践。保留暖白背景、墨绿强调、衬线标题和学习手记的表达，不增加新的品牌、工具依赖或内容类型。

## 本轮结构

首页顺序：简短介绍 → 最新日报及此前三期 → 实践手记 → 学习方向 → 关于常宝。

- 最新日报是主要阅读入口；累计数量缩为辅助信息。
- 保留全部三个实践项目，首先展开已有日报阅读入口的项目。AI 行业简报整理器与 Hypit 的具体成果仍待真实资料补充。
- 删除装饰插画、步骤条、重复的专题待整理说明和部分装饰英文，保留具体对象、当前状态和主要动作。
- 归档主题默认显示“全部主题”和篇数最多的四个主题，剩余主题放入原生折叠区；每个主题标明篇数。罕见主题链接打开时展开该区域并显示当前主题。
- 文章目录在 760px 及以下默认收起，较宽视口默认展开；用户仍可自行开合。无脚本时保留完整目录。
- 正文维持 16px，阅读说明与练习使用 14px，主要辅助信息使用 12px，筛选与收藏按钮最小高度为 44px。

## 状态与反馈

保留全文搜索、筛选网址、收藏及其失败提示、来源展开、复制链接和阅读进度。新增目录开合指示、按钮按压与主题选择过渡；首页最新日报使用 300ms 的一次出场，系统减少动效时关闭。

## 验收

本轮检查范围为生成内容、站内文件与锚点、语法、生成器可重复运行，以及根据生成 HTML 构造节点的 JavaScript 逻辑检查。逻辑检查覆盖组合筛选、主题链接恢复、空结果、收藏刷新后读回与写入失败、跨标签页更新，以及目录视口切换。

按现有浏览器使用约束，本轮未打开浏览器，因此未验证实际视觉、触控、键盘焦点、真实浏览器中的目录开合与动效，未进行独立视觉评审，不给视觉评分。后续实际页面验收应重点查看 390px、760px 与 1280px 下的标题换行、最新日报位置、筛选折叠与阅读目录。
