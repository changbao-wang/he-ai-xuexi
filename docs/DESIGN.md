# 和 AI 一起学习：2026-10-31 界面精修

## 用户任务与方向

这是常宝的个人学习记录站，同时容纳真实的成长经历与正在探索的项目。主动作是阅读最近一期日报，次要动作是了解实践项目和成长经历。

设计北极星：像一本持续更新的个人手记，用清楚的文字、温暖的纸色和深绿的墨色，让学习、经历与项目自然连在一起。

延续既有暖白、墨绿、衬线标题与无衬线正文，调整层级和构图，不重做品牌。没有本人照片时使用真实文字与经历索引，不制作虚构人像、成果图或空相册。

## 参考与区别

- [Maggie Appleton](https://maggieappleton.com/) 将持续生长的笔记与长文并列组织；本站取其清楚的内容入口，仍以中文日报为主，不复制插画与导航结构。
- [Brian Lovin](https://brianlovin.com/) 用简短身份说明连接文章与项目；本站采用精简的个人入口，将较长经历独立放到成长页。
- 首页避免大型空白封面、装饰插画和横向滚动。最新一期直接出现在介绍下方，手机上的个人入口压缩为两列概览。

## 内容与页面结构

- 首页：学习与实践介绍 + 个人概览 → 最新一期及前三期 → 五个实践方向 → 学习方向 → 三阶段成长线索 → 邮箱。
- 成长页 about/：个人概况 → 三个章节（在校创业、新媒体实践、AI 当前阶段）→ 实践与日报入口。
- 学历统一为“武汉大学研究生毕业”；不出现专业或未经确认的毕业年份。
- 长文基于本人本次自述，保留教育产品如何带出获客需求、获客实践如何形成代运营服务的因果关系。AI、OPC 与短剧方向按当前探索状态描述。
- 既有日报保留，目录与正文的“关于常宝”统一链接到成长页。

## 视觉规则与状态

- 纸色 #f8f7f3，主文字 #263e35，辅助文字 #58685f，操作强调 #315b4c；淡绿用于最新日报、状态和文章中的转折。
- 首页用不对称双栏呈现主标题与个人概览；最新日报采用单一浅绿底，与旁边开放排版的旧文列表区分。其余项目保持分隔行，不逐项套卡片。
- 中文正文15–17px，辅助信息12–14px；成长页正文约40字行宽，项目展开文字收窄。手机正文15–16px。
- 章节编号表示真实的叙事顺序，不附推测年份。小型区块名称帮助长页定位，去除首页原有装饰英文标签。
- 全文搜索、主题、收藏、复制链接、阅读进度、手机菜单、原生折叠均沿用现有实现。
- 缺照片阶段不展示上传按钮、失效作品链接或占位卡片；后续真实图片随对应项目加入。

## 动效与设备

- 首屏介绍400ms短促出场；个人概览延后60ms。按钮提供按压反馈，项目展开文字180ms出场，沿用原生折叠。
- 本轮为既有阅读站精修，成长页采用长文结构，保留原生滚动，不添加固定舞台或依赖额外库的展示动画。
- 系统减少动态效果时停用新增动效，内容无需等待脚本或动画才可见。
- 桌面目标1440px，手机390px，并检查360px、760px边界和720px的放大阅读等效重排。

## 维护

基础样式和交互仍是 assets/site.css、assets/site.js。本轮样式在 assets/refinement.css，由首页、成长页及日报模板统一引用。日报资源版本更新为v=4。

scripts/build_daily.py只更新首页日报标记之间的内容；新个人介绍、成长索引和联系入口位于标记之外，后续每日更新会保留。
